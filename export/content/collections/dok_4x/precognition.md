# Laravel Precognition

:::lead
Dok comes with Laravel Precognition ready to go, for live form validation without duplicate rules.
:::

[Laravel Precognition](https://laravel.com/docs/13.x/precognition) lets Statamic forms predict a submission's result before it happens. This means live validation for your forms, using the same rules as your backend - with no duplicate JavaScript logic.

Dok comes with Precognition pre-installed in case you ever need it.
