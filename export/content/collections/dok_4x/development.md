# Development

:::lead
Dok uses the same simple Vite setup as every new Statamic site, so you'll feel right at home.
:::


## Building in development
```shell
npm run dev
```

```shell
# For control panel assets, use this instead.
npm run cp:dev
```

## Building for production

```shell
npm run build
```

```shell
# For control panel assets, use this instead.
npm run cp:build
```
