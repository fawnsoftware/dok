# Updating

:::lead
Find out how updates work for Dok, and how to keep your plugins current.
:::

Dok is a starter kit, so there's no traditional update process. Once you've purchased and installed it, it's all yours. For bug fixes or new features, check the Git history.

Update plugins through Composer by running `composer update` on the package you want to upgrade.
